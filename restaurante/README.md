# Restaurante Sabor da Casa

Aplicativo Expo/React Native criado para a atividade DM6 de armazenamento de dados.

## Recursos

- Cardápio de comidas e bebidas
- Controle de quantidade por item
- Carrinho compartilhado com Context API
- Carrinho e histórico persistidos com AsyncStorage
- Resumo, total e confirmação do pedido

## Execução

```bash
npm install
npm start
```
